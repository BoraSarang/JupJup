# DESIGN — 줍줍 시리즈 통합 UI/UX

> v1.4 통합 앱 기준 (서비스-우선 내비게이션). Material 3 (네 서비스 통합).

## 1. 화면 구조

```
┌───────────────────────────────────────────────────────────────┐
│ 줍줍  [맥줍줍 ● 요금줍줍 ● 프롬프트 ● 커뮤니티]             [⋮] │  ← MaterialToolbar + ToggleGroup(4열) + 오버플로우
├───────────────────────────────────────────────────────────────┤
│                                                               │
│  대시보드: 네 서비스 카드 병렬 (시작 화면)                       │  ← DashboardFragment
│  (상태 도트·주소·통계·                                         │
│   [지금 수집/실행][중지/재개][서버], 활성 강조)                 │
│                                                               │
│  그 외 탭: 선택된 서비스의 화면 영역                             │  ← 기존 Fragment 재사용
│  (mac_* / plan_* / pj_* / cm_* 등, 16dp 패딩)                 │
├───────────────────────────────────────────────────────────────┤
│ [대시보드] [홈] [설정]      │ ← BottomNavigationView (3탭, R45)
└───────────────────────────────────────────────────────────────┘
```

드로어 없음 (v1.2 드로어 제거). 설정 진입은 하단 탭 유지, 앱 정보·버전은 툴바 `⋮` 오버플로우.

## 2. 네비게이션
- **상단 세그먼트**: 서비스 선택 (맥줍줍 / 요금줍줍 / 프롬프트 저널 / 커뮤니티) — 4열, 항상 표시, 현재 서비스 명시
- **하단 탭**: 대시보드 · 홈 · 설정 (R45: 수집 소스·알림 탭은 웹 이관으로 삭제, 대시보드는 서비스 무관 고정, 나머지는 선택된 서비스의 fragment 재사용, 단일 선택)
- 세그먼트 변경 시 대시보드로 강제 이동 (컨텍스트 모호성 제거), 그 외 탭은 백스택 미사용
- 화면 회전 시 서비스·기능 상태 복원

## 3. 상태 표시
- 앱바 타이틀 = 현재 서비스명 (맥줍줍 / 요금줍줍 / 프롬프트 저널 / 커뮤니티), 대시보드에서도 유지
- 시작 화면 "대시보드": 네 서비스 카드에 포트·실행 상태·포털 URL·통계 표시 + 카드에서 직접 **[지금 수집]·[수집 중지/재개]·[서버 시작/중지]** 조작
- 활성 서비스 카드 강조: `strokeWidth=2dp` + 서비스별 스트로크 색상 + 상단 활성 칩
- 서비스별 수집 토글 상태는 기존과 동일하게 영속 저장(`crawl_enabled`)

## 4. 테마·아이콘
- 앱 전역: `Theme.JupJup` (Material3 DayNight)
- 런처 아이콘: 제공된 아이콘 팩 (블루 버전, Adaptive 구성)
  - `mipmap-{mdpi~xxxhdpi}/ic_launcher.png · ic_launcher_round.png` (파란 배경 런처)
  - Adaptive: 흰 배경(`ic_launcher_background`) + 투명 `ic_launcher_foreground` (1024px)
  - 라운드 버전은 동일 규격 사용
- 색상 카테고리: `seed_primary`(테마 시드) + 아이콘 배경색 유지

## 5. 리소스 접두사 (필수, 충돌 방지)
- 서비스 모듈 리소스: `mac_*` / `plan_*`
- app 공용은 접두사 없음 (테마/아이콘/문자열/레이아웃)

## 6. 알림
- 채널: `jupjup_mac_server`, `jupjup_plan_server` (FGS dataSync)
- 서비스별 알림 실제 수신 구분

## 7. 참고
- 기존 두 앱의 화면·동작은 1:1 유지 목표 (탐색 구조만 바뀜)
- 콘텐츠 영역은 각 프래그먼트의 16dp 패딩 + 카드(재질)로 정돈

## 8. 프롬프트 저널 뉴스룸 (v1.12.0, PLAN_v7)

- 메타포: 정기간행물 발행 아카이브. 채널=신문명, 실행 1건=1개 호수(제N호).
- 웹(`pj_web`): Masthead(serif 저널명+날짜+제N호) + 채널 칩 + 발행주기 Pill + 2열(30% 아카이브 / 70% 지면).
- 아카이브 아이템: 제N호·날짜·조간/석간/단신·헤드라인 요약·취재 시간. 24h 내 SUCCESS 있으면 BREAKING, 없으면 휴간.
- 지면: kicker(채널명·호수) + H1(응답 첫 줄) + 발행 메타 + factbox 표(얇은 border).
- 설정 서랍 2탭: 브리핑 채널(지침서 폼) / 취재원 관리(공급자·키·모델).
- 스타일: Black/White + Blue 1개, Tailwind CDN + 바닐라 폴백, Noto Serif KR(폴백 serif 스택).

### 9.3 컴포넌트 명세

#### 사이드바 네비게이션
- **네비 아이템**: 아이콘 + 라벨 + 카운트 배지, active 시 `--primary` 배경 + 흰글자
- **필터 그룹**: `출처`(체크박스, 카운트 표시) / `유형`(라디오, 전체/오픈소스/프리/유료)
- **접힘 상태**: 데스크탑 72px 아이콘만, 모바일 ≤720px 오버레이 드로어

#### 카드 (`.app-card`)
- **아이콘**: 48px, radius 10px, 테두리 1px
- **타이틀 행**: 앱명(15px, 600) + 언어 컬러닷(8px) + NEW 도트(6px)
- **배지**: 라이선스(색상 구분) + 카테고리(중성)
- **설명**: 13px, `--secondary`, 2줄 클램프 (`line-clamp-2`)
- **메타**: ★스타수 + 버전 + 출처 링크
- **인터랙션**: hover 시 `translateY(-4px)` + `shadow-md`, focus-visible 아웃라인

#### 모달 (`.app-modal`)
- **히어로**: 64px 아이콘(radius 14px) + 타이틀 + 개발사 + 메타 pills(언어/라이선스/별점/NEW) + CTA 버튼 2개
- **탭**: 소개 / 특징 / 새기능 (ARIA tablist 패턴)
- **패널**: 마크다운 렌더링 (T-142 렌더러 이식), 한/영 토글 지원

#### 반응형 브레이크포인트
- ≤1100px: 그리드 2열
- ≤720px: 그리드 1열, 사이드바 드로어, 검색창 축소
- ≤480px: KPI 1열, 모달 히어로 세로 스택

### 9.4 다크모드
`prefers-color-scheme: dark` 미디어쿼리로 토큰 오버라이드 제공

### 9.5 접근성
- 시맨틱 HTML (`<aside role="navigation">`, `<main role="main">`, `<dialog role="dialog">`)
- ARIA: `aria-label`, `aria-expanded`, `aria-selected`, `aria-live`, `role="tablist/tab/tabpanel"`
- 키보드: Tab 순서, Enter/Space로 카드/버튼 조작, Esc로 모달 닫기
- 색상 대비: WCAG AA 만족 (주요 텍스트 4.5:1)
- `prefers-reduced-motion`: 애니메이션 비활성화

## 11. 네트워크 트래픽 측정 (vNext, PLAN_v18)

- **방식**: OS 카운터 미사용. `CrawlHttp` 초크포인트 + OkHttp 3종에서 실수신 바이트 직접 가산.
- **진실**: `common NetMeter`(메모리) → R42b에서 `CrawlLog rx/tx` DB 영속 + `/api/stats` 노출.
- **표시**: 전체(앱 합산) + 서비스별(노출 예정). 예산 초과는 WARN(실패 처리 아님).
