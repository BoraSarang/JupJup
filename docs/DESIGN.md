# DESIGN — 줍줍 시리즈 통합 UI/UX

> v1.2 통합 앱 기준. Material 3 (기존 두 앱 동일 토대).

## 1. 화면 구조

```
┌───────────────────────────────┐
│ [≡]  줍줍 시리즈 / 맥줍줍 / 요금줍줍 │  ← MaterialToolbar
│  =햄버거=                      │     (≡: 드로어 열기)
├───────────────────────────────┤
│                               │
│  인사이트: 두 서비스 카드 병렬    │  ← 시작 화면 (InsightFragment)
│  (상태 도트·주소·통계 3개·       │
│   [지금 수집][중지/재개][서버])   │
│                               │
│  그 외 탭: 활성 서비스의 화면 영역 │  ← 기존 Fragment 재사용
│  (mac_* / plan_* 등, 16dp 패딩) │
├───────────────────────────────┤
│ [인사이트] [수집 소스] [알림] [설정] │ ← BottomNavigationView
└───────────────────────────────┘
```

드로어(NavigationView, 좌측) 열림:

```
┌─[헤더: 줍줍 아이콘+이름]─────────┐
│ ● 줍줍 시리즈 (인사이트)          │
│ ● 맥줍줍 (MAC, 3000)            │
│ ● 요금줍줍 (PLAN, 3001)         │
└────────────────────────────────┘
```

## 2. 네비게이션
- **상단 앱바(햄버거)**: 드로어 — 줍줍 시리즈(인사이트) / 맥줍줍 / 요금줍줍
- **하단 탭**: 인사이트 · 수집 소스 · 알림 · 설정 (인사이트는 서비스 무관 고정, 나머지는 활성 서비스의 기존 fragment 재사용, 단일 선택)
- 서비스 전환 시 인사이트면 화면 유지(카드 최신화), 그 외 탭은 해당 서비스 fragment로 교체 (백스택 미사용)
- 화면 회전 시 서비스·기능 상태 복원

## 3. 상태 표시
- 앱바 타이틀 = 인사이트면 시리즈명, 그 외엔 현재 서비스명 (맥줍줍 / 요금줍줍)
- 시작 화면 "인사이트": 두 서비스 카드에 포트·실행 상태·포털 URL·통계 표시 + 카드에서 직접 **[지금 수집]·[수집 중지/재개]·[서버 시작/중지]** 조작
- 서비스별 수집 토글 상태는 기존과 동일하게 영속 저장(`crawl_enabled`)

## 4. 테마·아이콘
- 앱 전역: `Theme.JupJup` (Material3 DayNight)
- 런처 아이콘: 제공된 아이콘 팩 (블루 버전, Adaptive 구성)
  - `mipmap-{mdpi~xxxhdpi}/ic_launcher.png · ic_launcher_round.png` (파란 배경 런처)
  - Adaptive: 흰 배경(`ic_launcher_background`) + 투명 `ic_launcher_foreground` (1024px)
  - 라운드 버전은 동일 규격 사용
- 색상 카테고리: `seed_primary`(테마 시드) + 아이콘 배경색 유지

## 5. 리소스 접두사 (필수, 충돌 방지)
- 서비스 모듈 리소스: `mac_*` / `plan_*`
- app 공용은 접두사 없음 (테마/아이콘/문자열/레이아웃)

## 6. 알림
- 채널: `jupjup_mac_server`, `jupjup_plan_server` (FGS dataSync)
- 서비스별 알림 실제 수신 구분

## 7. 참고
- 기존 두 앱의 화면·동작은 1:1 유지 목표 (탐색 구조만 바뀜)
- 콘텐츠 영역은 각 프래그먼트의 16dp 패딩 + 카드(재질)로 정돈
