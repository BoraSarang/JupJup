# DESIGN — 줍줍 시리즈 통합 UI/UX

> v1.1 통합 앱 기준. Material 3 (기존 두 앱 동일 토대).

## 1. 화면 구조

```
┌───────────────────────────────┐
│ [≡]  맥줍줍 / 요금줍줍 (서비스명) │  ← MaterialToolbar
│  =햄버거=                      │     (≡: 서비스 드로어 열기)
├───────────────────────────────┤
│                               │
│     활성 서비스의 화면 영역       │  ← 기존 Fragment 재사용
│     (mac_home / plan_home 등)  │     (16dp 패딩, 카드 구성 유지)
│                               │
├───────────────────────────────┤
│ [서버 상태] [수집 소스] [알림] [설정] │ ← BottomNavigationView
└───────────────────────────────┘
```

서비스 드로어(NavigationView, 좌측) 열림:

```
┌─[헤더: 줍줍 아이콘+이름]─────────┐
│ ● 맥줍줍 (MAC, 3000)            │
│ ● 요금줍줍 (PLAN, 3001)         │
└────────────────────────────────┘
```

## 2. 네비게이션
- **상단 앱바(햄버거)**: 서비스 선택 드로어 (맥줍줍 / 요금줍줍)
- **하단 탭**: 서버 상태 · 수집 소스 · 알림 · 설정 (각 서비스 fragment 재사용, 단일 선택)
- 서비스 전환 시 현재 기능 탭의 fragment를 해당 서비스로 교체 (백스택 미사용)
- 화면 회전 시 서비스·기능 상태 복원

## 3. 상태 표시
- 앱바 타이틀 = 현재 서비스명 (맥줍줍 / 요금줍줍)
- 첫 번째 하단 탭 "서버 상태": 각 서비스 홈에서 포트·실행 상태·포털 URL 표시 (기존 UI 유지)
- 서비스 홈에 **수집 중지/시작 토글**: 일시정지(실행·예약 취소 + 영속 저장) / 재개

## 4. 테마·아이콘
- 앱 전역: `Theme.JupJup` (Material3 DayNight)
- 런처 아이콘: 제공된 아이콘 팩 (블루 버전, Adaptive 구성)
  - `mipmap-{mdpi~xxxhdpi}/ic_launcher.png · ic_launcher_round.png` (파란 배경 런처)
  - Adaptive: 흰 배경(`ic_launcher_background`) + 투명 `ic_launcher_foreground` (1024px)
  - 라운드 버전은 동일 규격 사용
- 색상 카테고리: `seed_primary`(테마 시드) + 아이콘 배경색 유지

## 5. 리소스 접두사 (필수, 충돌 방지)
- 서비스 모듈 리소스: `mac_*` / `plan_*`
- app 공용은 접두사 없음 (테마/아이콘/문자열/레이아웃)

## 6. 알림
- 채널: `jupjup_mac_server`, `jupjup_plan_server` (FGS dataSync)
- 서비스별 알림 실제 수신 구분

## 7. 참고
- 기존 두 앱의 화면·동작은 1:1 유지 목표 (탐색 구조만 바뀜)
- 콘텐츠 영역은 각 프래그먼트의 16dp 패딩 + 카드(재질)로 정돈
